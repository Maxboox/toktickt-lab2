# Lab 2 UI Specification

## Zen Green Theme
| Token | Hex | Usage |
|-------|-----|-------|
| Primary Green | #006B3C | Header, actions |
| Secondary Green | #0B7A46 | Links, hover |
| Pale Green | #EAF6EF | Selected |
| Error | #D32F2F | Error messages |

## Responsive Rules
| Viewport | Behavior |
|----------|----------|
| Desktop ≥ 992px | Multi-column |
| Tablet 768-991px | Two-column |
| Mobile < 768px | Vertical |
