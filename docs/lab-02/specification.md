# Lab 2 Sprint Engineering Specification

## 1. Sprint Goal
Cette sprint livre l'interface utilisateur Requester pour le système de tickets IT support.

## 2. Stakeholder Request Interpretation
L'équipe IT souhaite une application pour que les utilisateurs puissent soumettre des demandes de support.

## 3. Scope
### Included
- Écran de sélection du Development Requester
- Création de tickets avec validation
- Liste Mes Tickets avec recherche/filtres/tri/pagination
- Détail du ticket en lecture seule
- Upload de pièces jointes
- Suppression douce des pièces jointes
- Vérification d'ownership

### Excluded
- Authentification réelle
- Workflow IT Staff
- Commentaires publics/internes
- Changements de statut
